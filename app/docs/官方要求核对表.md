## 业务边界

最新完整验收见 `docs/完整测试报告_2026-10-26.md` 和 `artifacts/package_records/full_acceptance_summary.json`：干净环境15组检查、56项程序回归、最终46轮核心场景两遍通过。旧包缺时区数据、确认问句候选混淆及重复查询复用历史数据等问题的原失败记录保留，当前结论以修复后的复测为准。

- 只修改发票用途和备注；企业、编号、日期、金额、销售方、项目名、银行流水只读。
- 不执行真实记账、付款或税务申报。
- UI 只监听 `127.0.0.1`，不包含公网账户体系或后台管理系统。
