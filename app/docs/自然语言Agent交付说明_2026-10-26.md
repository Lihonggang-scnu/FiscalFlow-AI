# 自然语言财税办理模块交付说明

日期：2026-10-26。当前模块已完成约定功能，使用 DeepSeek-V4.1-Flash-1017，通过 `deepseek-flash` 接入。

## 可以做什么

| 用户要求 | 当前能力 |
|---|---|
| 查某企业某月发票金额、银行收入和支出 | 模型理解范围，调用程序查询，回复实际金额及必要依据 |
| 查哪些发票缺用途 | 调用独立只读缺项工具，按当前企业规则判断，不需要创建任务 |
| 月份或对象没说清 | 询问必要信息，接住后续补充 |
| 给已有发票填用途、改用途、追加或清空备注 | 实际保存、回查，并刷新相关进行中任务 |
| 查询另一家企业 | 检查权限，临时查询不改变当前办理企业 |
| 明确切换企业 | 更新当前办理企业，后续请求使用新状态 |
| 继续、更正、完成、取消或删除任务 | 调用已有任务管理，按用户和企业恢复当前进度 |
| 一句话提出多项明确要求 | 连续选择工具办理，分别返回实际结果 |
| “刚才那张”“上个月” | 结合近期对话、当前范围和北京时间解析，存在歧义时追问 |
| 修改金额等题外操作、越权或保存失败 | 说明可办理范围或实际失败原因 |

完整对话和工具状态由框架持久化；实际模型输入使用近期完整轮次，当前任务在注入前重新核对。程序身份、企业权限、金额和保存逻辑继续由业务服务执行。

## 直接使用

在 PowerShell 执行：

```powershell
& 'E:\AI-Chem\ChemIntent\.venv-cpython\Scripts\python.exe' 'D:\AI黑客松\TaxAgentHarness\scripts\chat.py'
```

启动后直接输入中文。默认用户 U001、甲企业 C001，输入 `/退出` 结束。

可以说：

```text
查一下甲企业2026年9月发票总额。
检查这个月哪些发票还没有用途。
把F002用途填为办公资料，保存。
刚才那张再追加备注，写部门采购。
临时查乙企业9月银行支出，不切换当前企业。
继续办理甲企业没有完成的任务。
```

用户明确提供的企业、年月和发票信息用于办理；缺少且无法从当前数据或上下文确定时，助手会询问。
