# 赛道二实施方案（准备阶段，阶段一已通过离线验收）

## 1. 目标和边界

作品最终要支持三个共用流程：按企业/月查询发票、银行收入和支出；在权限和用户明确要求下补充发票用途或备注并保存回查；多轮检查缺项并跨会话接续。模型负责理解、追问、选择工具和表达，程序负责身份、权限、金额、规则选择、保存和回查。

确定性基础、发票用途任务管理、自然语言 Agent、长期表达偏好和本机可信规则维护已分阶段交付。CLI 的结构化写入命令仍是可信入口，不依赖模型声称已获授权；Chainlit UI 和更广泛的真实模型质量验收仍未交付。

## 2. 最终架构

```text
显式用户/企业入口
        |
        v
        taxharness.cli / AgentRuntime
        |
        +-- permissions      程序绑定用户、企业、查看/修改权限
        +-- services          查询、规则选择、白名单修改、回查
         +-- storage           业务独立 SQLite、WAL、事务、版本和幂等事件
         +-- preferences      独立受控偏好 SQLite、用户/企业范围和动态上下文
        +-- importer          官方 Excel/规则文档只读导入
        +-- audit             脱敏的输入、规则、工具和结果记录
        +-- provider           后续 DeepSeek/Qwen-compatible adapter
```

独立数据库的核心对象为 companies、users、user_company_permissions、invoices、
bank_records、rules、operations、audit_events。金额只存整数分；业务主键始终包含企业编号，
发票/流水同号不得跨企业混淆。规则以 `(rule_id, version)` 保留，查询按企业、月份、
`effective_from` 和 `status=active` 选择，停用规则永不作为当前依据。

修改操作使用 `user:company:invoice:invoice_id:nonce` 格式的幂等键，并校验前缀与调用参数一致。
先查同范围已有 operation，再检查版本；同键同 payload 返回已提交结果，不重复写；同键不同
payload 拒绝；`expected_revision` 过期返回冲突；成功事务内更新、插入审计、重新读取并返回回查结果。

## 3. 阶段划分与验收

### 阶段一：确定性基础（本次）

官方 Excel 和业务规则文档只读导入项目独立 SQLite；提供金额查询、缺用途查询、规则依据、
权限判断、用途/备注修改、回查、重启恢复。离线检查固定核对：C001 2026-08 发票/支出/收入
`9046.35/5720.99/14850.75`，C001 2026-09 `9622.06/7180.74/13000.50`，
C002 2026-08 `13667.05/9341.10/18800.25`，C002 2026-09 `12667.24/8087.24/13700.75`，
以及无记录月份的 0.00 与无权限/失败的区别。验收还覆盖 U002 隔离、R002 旧版排除、
白名单、幂等重放、payload 冲突、版本冲突和源文件哈希不变。

### 阶段二：发票用途补全任务管理（已实现）

任务模块已提供每用户每企业一个未完成任务、`all_missing/selected`、任务恢复、范围更正、
保存后刷新、完成、取消、删除和结构化 CLI。任务只保存进度，当前发票和规则仍由现有服务实时查询。
长期表达偏好和本机可信规则维护已作为独立模块交付；偏好与任务、业务数据和对话分域保存。Agent 只读取规则，不提供规则写入工具。

### 阶段三：Agent/provider、长期表达偏好与规则维护（已实现）

在程序注入的用户/企业身份下接入工具循环和受控长期表达偏好。默认 DeepSeek 只配置官方端点和
`deepseek-flash` non-thinking；凭据从外部路径加载，绝不进入 prompt、结果或日志。真实模型
调用需单独授权和预算记录，质量比较固定同一业务 Case，不把 replay 或脚本演示当模型证据。

### 阶段四：UI 与业务验收（UI 已实现）

Chainlit 已接入并展示当前用户/企业、适用规则、待办、保存回执和脱敏运行记录；后续继续完成查询、
补充保存、多轮接续、跨会话记忆、规则变化和故障处理的浏览器真实业务验收。
