# 参赛作品启动说明

## 1. 环境

需要 Python 3.12–3.13 和本项目依赖。优先使用已有环境；换机器时可按 `requirements.txt` 安装，不要把虚拟环境打进作品包。

解压后，在包含 `README.md` 的目录打开 PowerShell；不要假设外层目录名称。

```powershell
$python = $env:TAXHARNESS_PYTHON
if (-not $python) { $python = (Get-Command python).Source }
$env:PYTHONPATH = (Join-Path (Get-Location) 'src')
```

## 2. 初始化独立业务库

首次启动 UI 或 CLI 前，使用项目 `data/` 中的只读材料创建独立业务副本：

```powershell
& $python -m taxharness.cli init-db `
  --database artifacts\chainlit\live-business.sqlite3 `
  --source-xlsx data\02_示例数据.xlsx `
  --rules-doc data\03_业务规则.docx.txt
```

初始化不会修改 `data/` 原文件。正式业务副本、偏好库和 checkpoint 与默认数据库分开。

## 3. 启动本机 Chainlit

```powershell
& powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start_chainlit.ps1 `
  -PythonPath $python `
  -Database artifacts\chainlit\live-business.sqlite3 `
  -AgentStore artifacts\agent\agent.sqlite3 `
  -PreferenceStore artifacts\chainlit\preferences.sqlite3 `
  -CheckpointStore artifacts\chainlit\checkpoints.sqlite3 `
  -Port 8010
```

浏览器访问 `http://127.0.0.1:8010`。页面设置选择用户和企业，点击“新对话”可清除旧消息并开启新的 Agent session。输入中文即可查询、追问、继续任务或按明确要求保存用途/备注。

停止本次启动的服务：

```powershell
& powershell -NoProfile -ExecutionPolicy Bypass -File scripts\stop_chainlit.ps1
```

脚本只停止自己记录的 PID，并保留 `artifacts/chainlit/chainlit.stdout.log` 和 `chainlit.stderr.log` 供诊断。

## 4. 结构化 CLI

```powershell
# 查询
& $python -m taxharness.cli query --user-id U001 --company-id C001 --month 2026-09

# 查看/创建任务
& $python -m taxharness.cli task-list --user-id U001 --company-id C001
& $python -m taxharness.cli task-create --user-id U001 --company-id C001 --month 2026-09 --scope all_missing

# 查看规则（维护入口）
& $python -m taxharness.cli rule-list --kind invoice_purpose --company-id C002
```

规则、偏好、任务和过程记录的命令示例见本包的 `README.md`、`docs/规则维护模块使用说明.md` 和 `docs/Chainlit使用说明.md`。

## 5. 凭据与范围

真实模型调用需要用户另行配置授权和预算。若使用外部凭据目录，启动前准备一个目录，其中只有一个非空 `.txt` 文件，然后设置环境变量；文件内容由评委自行准备，示例不包含真实 key：

```powershell
$env:TAXHARNESS_CREDENTIAL_DIR = '.\external-credentials'
# 该目录内放置评委自己的唯一非空 .txt 凭据文件
```

也可以使用 `TAXHARNESS_API_KEY` 环境变量。启动时用 `-BudgetUsd 0.00` 可保持模型关闭；获得授权后用明确的正预算启动，例如 `-BudgetUsd 0.30`。凭据不写入项目、ZIP、SQLite 或 UI 过程记录。作品默认只监听本机，不包含公网账户体系。

## 6. 打包

打包脚本只允许白名单文件进入 ZIP，并拒绝 SQLite、venv、ffmpeg、raw frames、凭据和个人绝对路径。可以先做不写 ZIP 的检查：

```powershell
& $python scripts\build_submission.py --dry-run
```

正式构建必须提供真实演示视频，视频会以 ZIP 根目录的 `演示视频.mp4` 保存：

```powershell
& $python scripts\build_submission.py `
  --video .\演示视频.mp4 `
  --output dist\TaxAgentHarness_submission_20261026.zip --force
```
