# 长期偏好管理

长期偏好决定助手怎样回答你。保存后，关闭程序、重新打开对话，仍会沿用。当前支持五类：回答语言（中文、英文）、详略（简短、标准、详细）、回答顺序（结果优先、依据优先）、三项金额的排列顺序，以及格式（自动、文字、表格）。

## 开始使用

在 PowerShell 执行，启动后直接输入中文：

```powershell
& 'E:\AI-Chem\ChemIntent\.venv-cpython\Scripts\python.exe' 'D:\AI黑客松\TaxAgentHarness\scripts\chat.py'
```

默认用户为 U001，当前办理企业为甲企业。输入 `/退出` 关闭；重新执行命令会开启新对话，并继续使用该用户保存的偏好。

## 保存和使用

例如：

```text
请记住，以后回答简短，用表格展示金额，先列银行支出，再列银行收入，最后列发票总额。
```

再查询：

```text
查甲企业2026年9月的发票总额、银行收入和银行支出。
```

助手会调用财税工具取得金额，再按你的偏好排列。仅查询发票总额时，排列偏好不会让它额外回答银行金额。

没有指定企业时，保存为你的通用偏好。企业专用设置覆盖同一项通用设置，例如：

```text
请记住，只在甲企业回答详细，其他企业仍按通用偏好。
```

临时查询乙企业会选用乙企业适用的设置，当前办理企业保持原值。

## 查看、更正和删除

可以直接说：

```text
查看我的所有长期偏好。
查看甲企业当前生效的偏好。
把我的通用回答格式改成文字，长期保存。
删除我在甲企业的回答详略偏好。
```

删除企业专用值后，该项重新采用通用值；删除通用值后，没有企业专用设置时采用助手默认方式。更正和删除会在后续调用中重新读取，历史聊天中的旧设置不会作为当前有效偏好。

临时要求这样说：

```text
这一次详细解释，用文字回答，不要改变长期设置。
```

这次请求优先，后续请求继续采用已保存的设置。
