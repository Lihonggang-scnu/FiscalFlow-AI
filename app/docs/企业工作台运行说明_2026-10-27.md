# 企业票据工作台

企业工作台为代账团队提供独立的多企业、多期间票据用途核实、会计确认和复核流程。它使用独立 SQLite 文件和 8011 端口；比赛 Chainlit 仍使用 8010 和原业务库。

## 启动

PowerShell：

```powershell
Set-Location 'D:\AI黑客松\TaxAgentHarness'
& .\scripts\start_enterprise.ps1
```

脚本会以隐藏进程运行服务，保存 PID 和独立 stdout/stderr 日志。浏览器打开 `http://127.0.0.1:8011`；停止使用 `& .\scripts\stop_enterprise.ps1`。第一次访问时创建系统管理员；之后所有人员必须用独立账号登录。账号密码以 scrypt 哈希保存，企业角色由管理员分配，不存在通过页面选择身份的入口。

企业业务数据库默认在 `artifacts/enterprise_delivery_20261027/enterprise.sqlite3`，模型调用账本沿用 `artifacts/agent/agent.sqlite3`。可通过启动脚本参数覆盖 Python、数据库、监听地址和端口。默认只监听本机地址；远程部署需使用机构的 HTTPS 反向代理及受控网络配置。

## 角色

- **管理员**：创建企业和账号，分配企业角色，配置默认币种、独立复核和允许的缺项处置，备份企业库。
- **会计**：导入文件、查看金额与规则、创建补充请求、生成及更正逐票草稿、确认发票字段、关闭工作项并导出结果。
- **复核人**：审批或退回会计确认的用途；启用独立复核时不能审批自己的提交。来源更新后，也可以重新核实尚未关闭的票据。
- **经办人**：登录后只看分配给自己的补充请求和对应票据，并提交回复。

撤销账号或企业授权后，后续读取和写入按当前授权拒绝。请求及迟到回复保留在其原工作项；迟到回复不会自动重开已关闭工作项，可由会计明确创建后续工作项。

## 导入和处理

1. 在“导入数据”选择企业，指定来源系统，上传 CSV 或 XLSX。页面先读取表头并自动匹配列；会计可用下拉框更正来源单据编号、日期、总额等字段的对应列。
2. 检查逐行异常和预览后确认导入。稳定业务身份为企业、来源系统、来源单据编号；文件/行内容摘要只用于识别来源版本。相同单据编号来自不同系统时会建立不同业务对象。
3. 空用途进入企业当前规则或页面展示的内部默认完整性策略；只有适用规则明确要求的票据才进入规则缺项待办。若适用规则已停用或冲突，页面明确显示无法判定。
4. 单价以原精度单独保存；当前汇总币种支持 CNY、GBP、USD、EUR，并逐币种统计，不会把不同币种相加。负数、退款或无法识别的币种进入异常清单，不会静默转成正常金额。
5. 会计可选择待办发票并创建应用内补充请求。经办人登录后回复；回复解析只产生带原话依据的逐票草稿。会计可调整票据对齐、用途或备注，再逐项确认。每项确认单独检查最新授权和 revision；冲突项保留原值并返回冲突回执，其他票据可以继续成功。
6. 确认后的发票进入待复核。复核通过后才可关闭；退回保留业务值。无法提供的回复保持待处理，只有管理员配置允许后，复核人才能明确批准保留空用途。
7. 关闭时保存当时票据和审核结果快照，最终 CSV 从快照导出。后续来源文件变化会使未关闭项回到待核实状态；已关闭结果保持原快照，并创建新的显式复查工作项。

“工作清单”支持客户、期间、状态筛选和分页；金额汇总直接按币种在数据库聚合。每次缺项查询仅返回所选页，工作项目标仍覆盖全部符合规则的票据。

## 规则和偏好

管理员或获授权会计可以在“规则”页面新增版本、启用或停用版本。页面可选择所有发票必填、达到金额门槛必填或不要求填写，并用金额输入框设置门槛。规则原版本会保留；停用当前适用版本不会自动回退到旧规则。

企业没有适用规则时，管理员可选择明确的内部默认策略：空用途进入人工核实，或不自动判定。页面会标明内部策略不是税务规则结论。用户个人偏好在“偏好”页面管理，只影响回复表达。

## 模型调用

工作台默认不发起实时模型调用。离线流程可以注入测试模型；模型草稿不会自行修改发票。需要真实 DeepSeek 调用时，运行环境必须同时明确启用企业与 provider 开关、存在有效预算，并通过闲时门控。每次调用先预留共享账本额度，超时或用量未知保留预留，不自动重试。设置两个开关不会绕过预算与时段限制。

```powershell
$env:TAXHARNESS_ENTERPRISE_LIVE_MODEL_ENABLED = 'true'
$env:TAXHARNESS_LIVE_MODEL_ENABLED = 'true'
```

## 备份和恢复

管理员可在“诊断与备份”创建在线一致性备份。检查备份完整性：

```powershell
& 'artifacts\full_acceptance_20261026\phase\clean_venv\Scripts\python.exe' scripts\enterprise_admin.py verify --source artifacts\enterprise_delivery_20261027\backups\enterprise-YYYYMMDD-HHMMSS.sqlite3
```

恢复前先停止 8011 服务。恢复会先为当前企业库生成 pre-restore 备份，并验证恢复源；命令仅允许操作 `artifacts/enterprise_delivery_20261027` 内的文件：

```powershell
& 'artifacts\full_acceptance_20261026\phase\clean_venv\Scripts\python.exe' scripts\enterprise_admin.py restore --database artifacts\enterprise_delivery_20261027\enterprise.sqlite3 --source artifacts\enterprise_delivery_20261027\backups\enterprise-YYYYMMDD-HHMMSS.sqlite3
```

FastAPI 文档仅在本机提供：`http://127.0.0.1:8011/api/docs`。运行健康接口不会读取凭据，也不会发起模型调用。
