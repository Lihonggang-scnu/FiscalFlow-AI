# 企业票据工作台

工作台用于多客户、多期间的票据用途核实：导入资料，向经办人请求补充，把回复整理成逐票建议，由会计确认、复核人员审核，最后关闭任务并导出。

## 本机开始使用

打开 <http://127.0.0.1:8011/>。首次使用时设置管理员账号和密码；在“账号与企业”创建企业、会计、复核人员和经办人，并分配各自的企业角色。个人使用过程中无需切换或冒充其他身份。

本机启动命令，在项目根目录的PowerShell运行：

```powershell
& .\scripts\start_enterprise.ps1
```

停止：

```powershell
& .\scripts\stop_enterprise.ps1
```

## 办理一个完整期间

1. 会计选择企业，打开“导入数据”，上传CSV或XLSX。用列选择框确认编号、日期、总额、币种等字段，查看异常后确认导入。
2. 在“工作清单”选择期间、打开任务，勾选票据，指定经办人并填写问题。经办人登录后在“补充请求”查看自己的票据、提交说明。
3. 会计从回复生成逐票建议，查看每条建议与原话。信息不清楚时继续核实；有明确事实后，可以更正票据对应关系或内容，再勾选确认。
4. 复核人员查看实际保存结果，通过或退回。会计完成待办后关闭任务，再点击“下载最终CSV”。关闭后的导出保留当时的已复核快照。

`examples/enterprise_invoices.csv` 提供四张模拟票据，包含两个期间，方便内部熟悉操作。真实使用时按机构允许的数据和处理方式导入。

## 独立解压部署

使用Python 3.12环境；已有环境可直接复用。安装依赖后在解压目录启动：

```powershell
python -m pip install -r requirements.txt
& .\scripts\start_enterprise.ps1 -PythonPath (Get-Command python).Source
```

模型默认关闭。管理员通过环境中的外部凭据、调用开关和预算文件配置DeepSeek，凭据不写入源码或业务库。两个调用开关为 `TAXHARNESS_LIVE_MODEL_ENABLED` 和 `TAXHARNESS_ENTERPRISE_LIVE_MODEL_ENABLED`；预算配置路径可用 `TAXHARNESS_ENTERPRISE_BUDGET` 指定。只有有效预算且处于闲时才发请求。压缩包的预算示例默认关闭付费调用。

本机这次交付另有已批准的10元预算，调用记录继续进入原共享账本。原比赛界面仍在8010。

更详细的账号、导入、规则、备份与恢复说明见 `docs/企业工作台运行说明_2026-10-27.md`；实际测试范围见 `docs/企业版内部交付验收报告_2026-10-27.md`。
