# 云帐房财税助手

这是一个本机运行的财税 Agent Harness，使用模拟企业、发票、银行流水和业务规则完成三类工作：

- 查询指定企业和月份的发票总额、银行收入与支出，并说明规则依据；
- 按用户明确要求补充发票用途或备注，保存后重新查询核对；
- 检查缺少用途的发票，跨轮次和新对话继续处理未完成任务。

页面设置中先选择用户和当前企业。输入自然语言即可开始，例如：

```text
查一下甲企业2026年9月的发票总额、银行收入和支出。
检查这个月哪些发票还缺用途，建立补全任务。
把 F002 用途填为办公资料，备注写部门采购，保存后告诉我结果。
```

“新对话”会保留长期偏好，但重新加载当前任务、规则和业务数据。规则维护使用本机可信命令行入口，不通过 Agent 自动改规则。
