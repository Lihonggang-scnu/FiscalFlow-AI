# 测试结果汇总

本目录保存 2026-11-10 的离线回归、真实模型交互和样本数据测试记录。完整交互、工具结果及隔离测试库位于 [experiments](experiments/)；同目录中保留了失败尝试和后续重测结果。

## 当前源码离线回归

在 `app/` 目录中执行：

```powershell
python -m pip install pytest
python -m pytest -q
```

上一版本整理时为 **173 项通过、2 项失败**，记录见 [历史 pytest 输出](current-pytest-20261110.txt)。这两项涉及财政部脱敏电子凭证样本，现已完成处理：

1. 解析结果保留发票类型。
2. 有可靠编号时匹配同票；脱敏编号等不足以区分票据时进入人工核对，避免把不同发票自动合并。

本轮同时覆盖复核内容变化、逐字段冲突、只读误调用、条件保存、旧回复迟到、双标签页、历史回执、任务进度和总上下文预算。最新完整离线回归 **203 项通过**，见 [本轮 pytest 输出](pytest-collaboration-final5-20261110.txt)。

“差额是否意味着未付款”的真实回复正确否定了这一推断；初版判分器误把被引用并否定的说法当成正面结论，修正判分器后对同一回复重新检查，见 [复核记录](experiments/semantics-20261110-224536-615783/review.json)。

一组 12 轮更正场景中，[对照版本](experiments/comparison/baseline-long_correction-20261110-225222-216342/results.json) 未找回更正后的用途，[升级版本](experiments/comparison/upgrade-long_correction-20261110-225302-105560/results.json) 找回并正确保存；输入分别为 414,113 和 195,821 tokens。两次结果展示这一具体场景的表现。

浏览器隔离样本已验证：从工作项查看回复并返回、旧页面复核时显示用途与备注变化、查看新内容后批准；数据库只记录了新内容的批准。见 [浏览器验收结果](browser-collaboration-20261110.json)。完整的导入到导出浏览器流程仍需补测。当前对明确的只读、暂不保存和常见条件表达已有程序检查；更多省略表达、复杂混合授权及目标交付模型仍需扩展测试。

## 样本

`datasets/china_mof_redacted/` 是财政部公开电子凭证结构的脱敏示例；`datasets/china_invoice_guard/` 包含中国票据格式和多模态样本；`datasets/multicurrency_v1/` 用于币种与状态测试。来源和适用范围见 [中国企业测试来源](../research/中国企业测试来源说明.md) 与各样本目录内的说明。
