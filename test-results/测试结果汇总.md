# 测试结果汇总

本目录保存 2026-11-10 的离线回归、真实模型交互和样本数据测试记录。完整交互、工具结果及隔离测试库位于 [experiments](experiments/)；同目录中保留了失败尝试和后续重测结果。

## 当前源码离线回归

在 `app/` 目录中执行：

```powershell
python -m pip install pytest
python -m pytest -q
```

本次整理后的完整回归为 **173 项通过、2 项失败**，记录见 [pytest 输出](current-pytest-20261110.txt)。这两项失败涉及财政部脱敏电子凭证样本：

1. 解析结果未返回已读取的发票类型。
2. 同一张发票的销方与受票方样本得到不同的发票身份，需要核对字段和去重策略。
